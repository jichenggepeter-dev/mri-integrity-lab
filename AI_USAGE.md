# Coding-agent usage

This project intentionally uses coding agents, as required by the course assignment.

## Uses

- Repository scaffolding and implementation suggestions.
- Test generation and debugging support.
- Refactoring and documentation checks.
- Reproducibility, data-leakage, and user-interface review.

## Human review

Jicheng Ge reviews the code, runs the experiments, interprets the results, and owns all submitted
work. Model outputs and generated figures are checked against saved metrics and test artifacts.

## Excluded use

The required three-to-four-page course report is not generated or written by an AI system.
